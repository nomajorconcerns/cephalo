Mechanism

      
It rides each agent's pre-tool hook.

      
No proxy, no patching the agent. Both Claude Code and Hermes can run a command before every tool call and read a decision from its output. Cephalo is that command. Click a step.

    

    

      
    
      
    
        
    
          
          
        
    
        
    
        
    
      
    
    
    
  
    

    



    
  
    
    
    
      
    What it can do
    
      
    A small CLI that is easy to check.
    
      
    Choose a command to replay it. The doctor, rules and test output below was captured from a real run (with your username and paths shortened); the rest is representative.
    
    
    
    
    
      
    
      
    
        
    
          
    
          
    
        
    
        
    
      
    
    
    
    
    
      
    cephalo rules show <id> prints one rule in full, including its pattern, and the default it was changed from.
    
      
    cephalo rules reset [--yes] backs up rules.yml, then rewrites it from the built-in defaults. Nothing is deleted.
    
      
    cephalo install / uninstall claude|hermes are idempotent, parse configs strictly, refuse invalid ones, and back up before writing. Uninstall removes only Cephalo's own entries.
    
      
    cephalo hook claude|hermes is the entry point the agents call. It prints pure JSON only, and fails open if anything breaks.
    
    
    
  
    

    



    
  
    
    
    
      
    Native on every OS
    
      
    One rule set, three platform adapters.
    
      
    An adapter decides where configs live, how paths and commands are cleaned up before matching, and which extra built-in rules apply. Rules are tested against the raw text and the cleaned copy, so cleaning can only add blocks, never remove one.

    Install
    
      
    Six steps, about five minutes.
    
      
    Cephalo is installed from its project folder. Your progress is saved in this browser, so you can tick steps off as you go.
    
    
    
    
    
      
      
        
    1. 
          
      Check you have Node.js
      
          
      Node.js 21 or newer (developed and tested on 24). You also need Claude Code, Hermes, or both.
      
          
      node --version
      
        
      2. 
        
    2. 
          
      Build it and put cephalo on your PATH
      
          
      From the Cephalo project folder:
      
          
      
          
      Then cephalo --help should show the banner and command list.
      
        
      3. 
        
    3. 
          
      Run cephalo init
      
          
      It prints a plan first, asks before changing anything, creates ~/.cephalo/rules.yml from the defaults, and adds its hook to Claude Code and (if found) Hermes. Every edited file is backed up to <file>.cephalo-backup-<timestamp>. Add --yes to skip the question.
      
          
      cephalo init
      
        
      4. 
        
    4. 
          
      Restart Claude Code
      
          
      Claude Code reads hooks when it starts, so a running session will not pick the new hook up.
      
        
      5. 
        
    5. 
          
      Approve the hook in Hermes
      
          
      Hermes skips a hook command until you approve it once. Start an interactive hermes, accept the prompt, then check the list. It should say allowed, not not allowed.
      
          
      hermes hooks list
hermes hooks doctor
      
        
      6. 
        
    6. 
          
      Verify
      
          
      doctor checks the rules file, runs a self-test, and confirms both hooks. Then prove a block, and watch it arrive live.
      
          
      cephalo doctor
cephalo test "DROP TABLE users"
cephalo watch
      
        
      7. 
      
    
      
    
        
    
          
    
            
            
          
    
          
    
          
     
    
        
    
        
    Undo it any time.
    
          cephalo uninstall claude
    cephalo uninstall hermes
    removes only Cephalo's entries, after a backup. npm unlink -g cephalo removes the command.
    
        
    Your rules, your file. Edit ~/.cephalo/rules.yml. Defaults added in later versions are not pushed into an existing file; cephalo rules lists what is missing.
    
      
    
    
    
  
    

    



    
  
    
    
    
      
    Honest limits
    
      
    A seatbelt, not a vault.
    
    
    
    
    
      
    It matches patterns.
    Cephalo sees command text, not what a script does once it runs. A command assembled at runtime, or hidden inside a script file, can slip past. Cleaning catches common tricks like r''m, not all of them.
    
      
    It fails open.
    If the hook crashes or its input is not valid JSON, the call is allowed and the error is logged. A block is never weakened by a logging failure.
    
      
    Windows is the proven one.
    The Windows adapter has run on a real machine. macOS and Linux are covered by unit tests only. Agents can also edit Cephalo's own files unless you add a rule against it.
